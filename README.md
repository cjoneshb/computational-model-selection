# Computational Model Selection for Momentary Behavior

Model code and simulations accompanying

> Jones, C. M., et al. (in preparation). *A principled framework for selecting and formalizing computational models of momentary behavior: Two illustrative demonstrations grounded in self-regulation theory.*

The repository will contain the model specifications for the two applications (a cybernetic control system for snacking, a dual-process model for smoking), the cross-validated cross-architecture comparisons, and the simulation code.

**Status:** Code will be added once the manuscript and data-use agreements are finalised. Raw data are not included.

Contact: Christopher M. Jones, Center for Preventive Medicine & Digital Health, Medical Faculty Mannheim, Heidelberg University
